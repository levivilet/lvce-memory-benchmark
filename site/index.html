READ THE NUMBERS WITH CONTEXT

A small number needs a clear definition.

Why not just take the minimum?

A single dip can reflect startup, shared pages, swapping, or a dead helper. This benchmark uses repeated trials, whole-cgroup membership, and verified edits. There is no forced garbage collection and no system-wide cache dropping.

What is being compared?

Official desktop builds opening the same 100-line plain-text file, fresh profiles, no user-installed extensions, and identical window size. Built-in features remain. No language server or large-project indexing workload is exercised. Electron sandboxing is disabled for this CI environment.

What can change the result?

Host RAM, caches, allocator behavior, application versions, background activity, and graphics drivers can all matter. These Linux results use Xvfb and software rendering; they do not measure physical GPU VRAM or predict a hardware-accelerated desktop’s footprint.

Why do memory tools disagree?

PSS apportions shared pages. Summed RSS counts shared pages once per process. Cgroups also charge file cache and kernel memory, with sharing charged differently. Reserved virtual address space is not resident RAM. A screenshot’s MB value is not directly comparable to this report’s MiB (1,048,576 bytes).
