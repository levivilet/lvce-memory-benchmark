How releases and downloads are verified

Stable releases come from the official LVCE GitHub releases API and Microsoft VS Code stable release API. Every attempted archive URL and SHA-256 checksum is recorded with its result artifact. Historical releases use their bundled runtime. A release is charted only when all three normal-memory trials succeed.
